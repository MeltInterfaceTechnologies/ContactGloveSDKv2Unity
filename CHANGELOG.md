# Changelog

## 1.0.0

- Initial release of ContactGlove Unity SDK V2, a managed client for DivingStation Protocol v2.
- The `v2` in the package identifier `com.melt-interface-technologies.contactglove.sdkv2` and C# namespaces identifies the protocol generation; `1.0.0` is the SDK package version.
- Include the Basic Sample with raw/retargeted skeleton visualization, device information and body vibration controls.
- Link to the public English and Japanese installation and API guides.
